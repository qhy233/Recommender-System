# 基于大模型智能体的心理学调查仿真系统项目



## 1. 摘要
构建“数字化心理实验室”：批量生成具有指定人格/情境的人设智能体，使其完成标准心理量表作答，并自动输出心理测量学分析（如信度/效度、组间差异、相关矩阵与可视化），用于低成本的群体心理仿真实验。

## 2. 背景与动机
- **传统心理学实验成本高**：招募大样本被试耗时耗资；本项目尝试用 API 调用在分钟级生成可分析的大样本仿真数据。
- **研究/应用价值**：可在不触碰真人伦理风险的前提下，对高压/极端情境进行“社会预演”，快速做假设检验与方法论验证。

## 3. 项目目标与研究问题
1. **仿真可信度**：大语言模型是否能“听懂人设”，并在量表维度上呈现可检验的组间差异？
2. **稳定性**：同一人设智能体在清除记忆后复测，结果是否稳定（复测信度）？
3. **情境效应**：给定压力情境，人设是否会在相关量表上显著偏离常模/对照？
4. **工程可用性**：能否形成“人设→量表→仿真→统计→报告”的自动化闭环与可视化界面？

## 3.5 项目创新点
1. **心理测量学闭环评估**：以标准量表与信度/效度指标评估“仿真是否可信”，输出可复现统计报告，而非仅展示对话。
2. **参数化人设批量采样**：将智能体视为“人设参数 + 提示模板”的可配置样本，低成本生成大样本仿真数据。
3. **推理阶段一致性优化**：引入“生成—评估—修正”闭环（Actor–Critic 思路），用规则与一致性约束降低随机漂移、减少异常数据。

## 4. 系统总体方案
### 4.1 核心思想：Silicon Sampling + 参数化 Prompt
- 将 **智能体视为参数化提示模板配置**（而非独立程序）；通过循环调用同一大语言模型 API 批量采样形成“硅基被试”。
- 数据流：人设库（JSON/Excel）→ 提示模板组装（Python）→ 大语言模型 API → 解析与清洗 → 统计分析 → 报告与可视化。

### 4.2 模块划分
1. **人设生成/管理模块**：定义年龄、职业、人格特征、经历背景与当前状态；支持批量导入/生成。
2. **量表题库模块**：可扩展量表题库（含反向计分、维度映射、评分区间）。
3. **仿真引擎（批量推理）**：按 智能体 × 题目 循环调用；输出解析为结构化数据。
4. **数据清洗与一致性检查**：输出格式校验、缺失/异常处理；冲突触发反思重采样。
5. **统计分析模块**：信度/效度、组间检验、复测相关、效应量与可视化。
6. **报告与可视化模块**：自动生成图表与结论摘要；提供基础交互界面（如 Streamlit）。

### 4.3 技术栈
Python 3.10+；Pandas/NumPy；scipy/pingouin；factor_analyzer；Streamlit；模型通过 DeepSeek 或 OpenAI API 调用。

## 5. 关键方法：推理阶段优化
目标：不重训模型，通过提示工程与控制流降低刻板化/随机性，提高仿真数据的信度与效度。

1. **少样本示例锚定（Few-shot）**：用 1–3 个示例固定语气与评分标尺，降低随机漂移。
2. **思维链（内心独白→打分）**：先生成“心理活动/自我反思”，再给 1–5 分，兼得定量分数与可分析的定性文本。
3. **动态状态注入**：将“当前情绪/疲劳”等状态写入提示模板，并随题序更新，模拟测验过程中的状态累积效应。
4. **自洽性检验 + 反思重采样**：当回答与人设明显冲突时，触发批评/反思并重答，减少异常数据。
5. **Actor–Critic 推理闭环（生成→评估→修正）**：引入“生成器-评估器”式的推理优化控制流：生成器按人设与情境对题项生成“心理活动 + 分数”；评估器检查分数越界、反向题逻辑、与人设/情境冲突、同维度历史矛盾；未通过则将评估反馈作为约束块注入下一轮生成，并采用“最小改动”原则进行修正；记录触发原因、重采样次数与最终选择依据。
6. **去偏问法（第三人称投射 + 强迫选择）**：为降低“社会赞许性/过度积极”倾向对量表的系统性偏差，在同一量表中设置小比例对照题：
   - **第三人称投射**：将题干改写为“这个角色通常会如何想/如何做”，要求按角色而非“我”作答。
   - **强迫选择**：对少量题项使用二选一（A/B）形式，减少中庸与迎合。
   - 与原题并行采样，比较两种问法下的分布差异与方差变化，作为去偏效果证据。


## 6. 实验设计与评价指标
### 实验 I：结构效度（Construct Validity）
- 设计：内向组 vs 外向组（各 50）
- 量表：大五人格量表（BFI）
- 检验：外向性维度得分差异（t-test，p < 0.05；报告效应量）

### 实验 II：复测信度（Test–Retest Reliability）
- 设计：同一批 智能体，T1 与清除记忆后的 T2 复测
- 指标：两次得分 Pearson 相关（目标 > 0.7）

### 实验 III：情境模拟（Scenario Simulation）
- 设计：设定“期末考试且挂科风险极大”的大学生情境
- 量表：SAS（焦虑自评量表）
- 预期：得分显著高于常模/对照组（并报告效应量与置信区间）



### 实验 IV：去偏问法对照（De-biasing Check）
- 设计：同一批智能体，对同一量表抽取 5–10 个题项设置“第三人称投射/强迫选择”版本，与原题并行作答。
- 指标：比较两种问法下的得分分布、方差与极端值比例；检查是否减少“过度积极/迎合”导致的压缩分布。

### 实验 V：同构题一致性（Isomorphic Robustness, 小规模）
- 设计：从 BFI 或 SAS 中抽取 5–10 个题项，生成 2–3 个语义等价改写版本；同一批智能体分别作答。
- 指标：原题与改写题的题项相关/一致性（相关系数或 ICC），并比较维度聚合得分的稳定性，用于回应“量表背题/语料污染”的质疑。

### 统一输出
- 维度得分分布、组间差异检验、复测相关、Cronbach’s α
- 题项/维度相关矩阵
- 思维链文本的基础分析（词频/主题/聚类，作为“拟人推理”的证据）
- 去偏问法对照结果摘要（原题 vs 投射/强迫选择）
- 同构题一致性指标（题项相关或 ICC）

## 7. 数据与实现细节
### 7.1 数据结构
- `personas.xlsx/json`：age、occupation、personality、background、state…
  - 字段最小集：`agent_id, group_label(实验分组), persona_text(人设摘要), scenario_id(情境), baseline_state(情绪/压力/疲劳), seed`
  - 批量生成保留：`prompt_version`（用于复现实验）、`created_at`（追溯）
- `scales/`：题目、反向计分、维度映射、评分区间
  - 补充字段：`scale_id, item_id, dimension, reverse(bool), likert_min, likert_max`
  - 反向题统一在计分阶段处理（例如 1–5：`x' = 6 - x`）
- `responses.csv`：agent_id、scale_id、item_id、score、cot_text、timestamp、meta
  - `meta` 记录：模型名、temperature、top_p、重试次数、解析是否成功、反思重采样原因

### 7.2 输出格式规范
为保证可解析与可复现，统一输出为 JSON，字段至少包含：`agent_id, scale_id, item_id, dimension, score, cot`。

### 7.3 质量控制
- 格式校验 + 自动重试；记录失败原因（例如：缺字段/分数越界/无法解析）。
- 分数校验：`score` 必须落在量表评分区间 `[likert_min, likert_max]`；否则判为无效并重试。
- 冲突检测触发反思重答；保留重采样日志用于方法部分说明（例如：人设/情境与回答明显矛盾）。
- 可复现记录：每次实验运行保存 `run_config`（模型、温度、prompt_version、样本量、分组规则、时间戳）。
- 计分与统计（落地口径）：
  - 先按题库规则反向计分，再按维度聚合得到维度总分（sum/mean 二选一并固定）。
  - 信度：对每个维度计算 Cronbach’s α；复测信度用 T1/T2 维度得分相关（Pearson 或 Spearman）。
  - 效度：已知组（内向/外向）做组间差异检验（t-test 或 Mann–Whitney），并报告效应量（Cohen’s d）；输出维度相关矩阵（热力图）作为结构/收敛区分证据。
