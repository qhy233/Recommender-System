# 基于大模型智能体的心理学调查仿真系统项目



## 1. 摘要
构建一个“数字化心理实验室”：批量生成具有指定人格/情境的人设智能体，让其完成标准心理量表作答，并自动输出心理测量学分析（如信度/效度、组间差异、相关矩阵与可视化），用于低成本的群体心理仿真实验。

## 2. 背景与动机
- **传统心理学实验成本高**：招募大样本被试耗时耗资；本项目尝试用 API 调用在分钟级生成可分析的大样本仿真数据。
- **研究/应用价值**：可在不触碰真人伦理风险的前提下，对高压/极端情境进行“社会预演”，快速做假设检验与方法论验证。

## 3. 项目目标与研究问题
1. **仿真可信度**：LLM 是否能“听懂人设”，并在量表维度上呈现可检验的组间差异？
2. **稳定性**：同一人设智能体在清除记忆后复测，结果是否稳定（复测信度）？
3. **情境效应**：给定压力情境，人设是否会在相关量表上显著偏离常模/对照？
4. **工程可用性**：能否形成“人设→量表→仿真→统计→报告”的自动化闭环与可视化界面？

## 4. 系统总体方案
### 4.1 核心思想：Silicon Sampling + 参数化 Prompt
- 将 **Agent 视为参数化 Prompt 配置**（而非独立程序）；通过循环调用同一 LLM API 批量采样形成“硅基被试”。
- 数据流：人设库（JSON/Excel）→ Prompt 组装（Python）→ LLM API → 解析与清洗 → 统计分析 → 报告与可视化。

### 4.2 模块划分
1. **人设生成/管理模块**：定义年龄、职业、人格特征、经历背景、（可选）当前状态；支持批量导入/生成。
2. **量表题库模块**：可扩展量表题库（含反向计分、维度映射、评分区间）。
3. **仿真引擎（批量推理）**：按 Agent×题目循环调用；输出解析为结构化数据。
4. **数据清洗与一致性检查**：输出格式校验、缺失/异常处理；（可选）冲突触发“反思重采样”。
5. **统计分析模块**：信度/效度、组间检验、复测相关、效应量与可视化。
6. **报告与可视化模块**：自动生成图表与结论摘要；提供基础交互界面（如 Streamlit）。

### 4.3 技术栈
Python 3.10+；Pandas/NumPy；scipy/pingouin；factor_analyzer；Streamlit；模型通过 DeepSeek 或 OpenAI API 调用。

## 5. 关键方法：推理阶段优化
目标：**不重训模型**，通过提示工程与控制流降低刻板化/随机性，提高仿真数据的信度与效度。

1. **Few-shot（少样本示例锚定）**：用 1–3 个示例固定语气与评分标尺，降低随机漂移。
2. **CoT（内心独白→打分）**：先生成“心理活动/自我反思”，再给 1–5 分，兼得定量分数与可分析的定性文本。
3. **动态状态注入**：将“当前情绪/疲劳”等状态写入 Prompt，并随题序更新，模拟测验过程中的状态累积效应。
4. **自洽性检验 + 反思重采样**：当回答与人设明显冲突时，触发批评/反思并重答，减少脏数据。

## 6. 实验设计与评价指标
### 实验 I：结构效度（Construct Validity）
- 设计：内向组 vs 外向组（各 50）
- 量表：大五人格量表（BFI）
- 检验：外向性维度得分差异（t-test，p < 0.05；报告效应量）

### 实验 II：复测信度（Test–Retest Reliability）
- 设计：同一批 Agent，T1 与清除记忆后的 T2 复测
- 指标：两次得分 Pearson 相关（目标 > 0.7）

### 实验 III：情境模拟（Scenario Simulation）
- 设计：设定“期末考试且挂科风险极大”的大学生情境
- 量表：SAS（焦虑自评量表）
- 预期：得分显著高于常模/对照组（并报告效应量与置信区间）

### 统一输出（报告自动生成）
- 维度得分分布、组间差异检验、复测相关、（可选）Cronbach’s α
- 题项/维度相关矩阵
- CoT 文本的基础分析（词频/主题/聚类，作为“拟人推理”的证据）

## 7. 数据与实现细节（Implementation Sketch）
### 7.1 数据结构
- `personas.xlsx/json`：age、occupation、personality、background、state…
- `scales/`：题目、反向计分、维度映射、评分区间
- `responses.csv`：agent_id、scale_id、item_id、score、cot_text、timestamp、meta

### 7.2 输出格式规范
为保证可解析与可复现，统一输出：
- `心理活动：...`
- `分数：X`

### 7.3 质量控制
- 格式校验 + 自动重试；记录失败原因
- 冲突检测触发反思重答；保留重采样日志用于方法部分说明


## 8. 评分维度映射
- 选题价值 / 研究意义：强调“低成本群体仿真”“高风险情境社会预演”“方法论验证”
- 研究设计 / 分析过程：三组实验 + 心理统计指标 + 可复现实验流程
- 研究结论：给出可推广的系统框架与可复用的推理优化策略；说明局限与后续工作

## 9. 预期成果
1. 可运行系统：批量人设、可选量表、自动统计分析与报告、基础可视化界面
2. 三个核心实验结果：结构效度、复测信度、情境模拟（含统计检验与图表）
3. 可复用资产：Prompt 模板、人设/量表配置格式、推理阶段优化策略说明与实验脚本
